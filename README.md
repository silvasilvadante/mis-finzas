# Mis Finanzas – Meta Departamento

App personal para controlar ingresos y gastos, frenar los gastos hormiga,
separar Estudio y Personal, llevar mis cuentas de ahorro y avanzar hacia
la cuota inicial de mi departamento.

- Funciona sin internet y se instala en el celular (Chrome → "Instalar app").
- Los datos se guardan solo en el celular; este repositorio contiene solo el código.
- Haz respaldos desde 🏠 Meta → "Respaldo de mis datos".
